# UNIDO — United Nations Industrial Development Organization

Dossier on registry-like systems for governing-body mandates. Part of the
survey behind the `/system` mandate-registry column; taxonomy and scoring
scheme in [`../un-system-registries.md`](../un-system-registries.md).

## Systems

- **Session Documents** (Session Documents) — <https://www.unido.org/resources/policymaking-organs/general-conference/sessions/14th-session/decisions-and-resolutions-general-conference>

## Point assessment

| Point | Assessment |
| --- | --- |
| 1 documents | yes |
| 2 mandates (active) | no — per-session compilation PDFs only; no in-force/superseded distinction |
| 3 budget-linked | no — budget/funding transparency lives in COMPASS at project level, not linked to GC/IDB decisions |
| 4 implementation-linked | no evidence in round 1 |
| 5 results-linked | no — results (outcomes/outputs) are reported per project in COMPASS/IATI, not against governing-body decisions |
| 6 interoperability | deferred (later round) |

## Related portals (not linked to mandates)

- **UNIDO COMPASS** — <https://compass.unido.org/> — successor to the Open Data Platform (open.unido.org now 301-redirects there); IATI-based transparency portal with per-project budgets, outcomes/outputs, donors and documents. Organized by projects/countries, not by decisions (verified; JS single-page app).
