# UNEP — United Nations Environment Programme

Dossier on registry-like systems for governing-body mandates. Part of the
survey behind the `/system` mandate-registry column; taxonomy and scoring
scheme in [`../un-system-registries.md`](../un-system-registries.md).

## Systems

- **Monitoring & Reporting Portal** (Implementation Tracker) — <https://unea.unep.org/monitoring/>

## Point assessment

| Point | Assessment |
| --- | --- |
| 1 documents | yes |
| 2 mandates (active) | no — no active/superseded or completed labels found on the monitoring portal or the resolutions repositories |
| 3 budget-linked | no — the monitoring framework maps each resolution to the Programme of Work and Budget (structural linkage only, no monetary amounts per resolution) |
| 4 implementation-linked | yes |
| 5 results-linked | no — per-resolution reporting is implementation-status (secretariat updates, voluntary national reports), not results/outcomes; the results framework lives in the PoW/Medium-Term Strategy |
| 6 interoperability | deferred (later round) |

## Related portals (not linked to mandates)

- **Resolutions Portal** — <https://resolutions.unep.org/> — repository of GC/UNEA resolutions, decisions and declarations since 1973 (JS app, little crawlable content).
- **Legacy intergovernmental resolutions platform** — <https://apps1.unep.org/resolutions/> — draft resolutions, co-sponsorship and background docs for UNEA 3–7; marked "no longer used for UNEA submissions" (archive).

## Notes

- Portal created per UNEA res 4/22; implementation-status and secretariat-reporting dashboards; Member State report submission behind login.
- Round 2 fetch limits: unea.unep.org redirect-loops and www.unep.org returns 403 for non-browser clients; portal characterization rests on round-1 verification plus search-indexed portal descriptions (which confirm resolution-to-PoW structural linkage, no amounts).
