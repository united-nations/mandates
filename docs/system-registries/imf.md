# IMF — International Monetary Fund

Dossier on registry-like systems for governing-body mandates. Part of the
survey behind the `/system` mandate-registry column; taxonomy and scoring
scheme in [`../un-system-registries.md`](../un-system-registries.md).

## Systems

- **Selected Decisions** (Decisions Database) — <https://www.imf.org/en/publications/selected-decisions/selected-decisions-list>

## Point assessment

| Point | Assessment |
| --- | --- |
| 1 documents | yes |
| 2 mandates (active) | yes — Selected Decisions compiles decisions currently applicable; lapsed/superseded decisions are deleted from each issue |
| 3 budget-linked | no — no system connects decisions to budget/financial information; decision pages are text-only |
| 4 implementation-linked | no evidence in round 1 |
| 5 results-linked | no — no results/outcome reporting against specific Board decisions found |
| 6 interoperability | deferred (later round) |

## Related portals (not linked to mandates)

None verified. imf.org serves HTTP 403 to non-browser clients, so candidate
pages (IMF Finances, Annual Report) could not be fetch-verified in round 2.

## Notes

- Selected Decisions (44th issue) online with per-decision pages; Board of Governors resolutions included.
- The compilation's front matter (43rd issue) states that decisions which lapsed or were superseded are removed — i.e. it functions as an in-force compilation, though "Selected" means it is curated, not exhaustive.
