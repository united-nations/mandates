# IFAD — International Fund for Agricultural Development

Dossier on registry-like systems for governing-body mandates. Part of the
survey behind the `/system` mandate-registry column; taxonomy and scoring
scheme in [`../un-system-registries.md`](../un-system-registries.md).

## Systems

- **Members Platform** (Session Documents) — <https://webapps.ifad.org/members/gc>

## Point assessment

| Point | Assessment |
| --- | --- |
| 1 documents | yes |
| 2 mandates (active) | no — round 2 confirmed: no consolidated in-force/superseded list or status index found; resolutions exist only as per-session PDF compilations |
| 3 budget-linked | no — no system links resolutions to budget data. (Inherent overlap only: the annual administrative budget and each replenishment are themselves adopted by GC resolutions carrying amounts, but nothing connects resolutions to financial data as a system) |
| 4 implementation-linked | no evidence in round 1 |
| 5 results-linked | no — results reported against the per-replenishment Results Management Framework (RIDE report), not against specific GC resolutions |
| 6 interoperability | deferred (later round) |

## Related portals (not linked to mandates)

- **Operations Dashboard** — <https://www.ifad.org/en/operations-dashboard> — key performance/operations data (projects, countries). ifad.org returns 403 to non-browser clients; verified via search descriptions.
- **PRISMA Dashboard** — <https://www.ifad.org/en/prisma-dashboard> — follow-up status of evaluation recommendations (evaluation-side analogue of decision tracking, but for IOE recommendations, not GC resolutions).

## Notes

- Members Platform per-session document sets incl. compiled GC resolutions; no cross-session search.
- IFAD's transparency stack (Operations Dashboard, RMF, PRISMA, IATI) is entirely project/replenishment-framework oriented; governing-body resolutions sit outside it.
