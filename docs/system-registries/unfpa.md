# UNFPA — United Nations Population Fund

Dossier on registry-like systems for governing-body mandates. Part of the
survey behind the `/system` mandate-registry column; taxonomy and scoring
scheme in [`../un-system-registries.md`](../un-system-registries.md).

## Systems

- **Decision Tracking Tables** (Decision Tracking) — <https://www.unfpa.org/executive-board/decisions-board-listing>

## Point assessment

| Point | Assessment |
| --- | --- |
| 1 documents | yes |
| 2 mandates (active) | partial — per-request status legend: green = "completed" (action done **or decision no longer relevant**) or "ongoing"; yellow = "partially completed"; explicit obsolescence marker but no corpus-level in-force registry |
| 3 budget-linked | no — 2026 tracking table verified: columns Decision / Category / Responsible division / Request / Deadline / Progress / Status, no financial amounts |
| 4 implementation-linked | yes |

## Related portals (not linked to mandates)

- **UNFPA Transparency Portal** — <https://www.unfpa.org/transparency-portal> — programme expenses by country/region, thematic programme activity and core/non-core resource type, 2014–2024; not organized by Board decisions.
