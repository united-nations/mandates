# FAO — Food and Agriculture Organization

Dossier on registry-like systems for governing-body mandates. Part of the
survey behind the `/system` mandate-registry column; taxonomy and scoring
scheme in [`../un-system-registries.md`](../un-system-registries.md).

## Systems

- **Conference Resolutions Portal** (Resolutions Database) — <https://resolutionsportal.fao.org/>

## Point assessment

| Point | Assessment |
| --- | --- |
| 1 documents | yes |
| 2 mandates (active) | yes |
| 3 budget-linked | no — portal has a "Budget" subcategory (285 resolutions) but no financial data per resolution; Transparency Portal budget data is organized by PWB/Strategic Framework, not resolutions |
| 4 implementation-linked | no evidence in round 1 |
| 5 results-linked | no — Programme Implementation Report (PIR, incl. a PIR Results View on the Transparency Portal) reports against Strategic Framework results; the PIR regime was itself created by Conference Res 10/2009 but reporting is not per-resolution |
| 6 interoperability | deferred (later round) |

## Related portals (not linked to mandates)

- **FAO Transparency Portal** — <https://www.fao.org/transparency/en> — Programme/Budget & HR dashboard (PWB, biennium comparison), project dashboard (by country, partner, SDG, "Four Betters"), voluntary-contribution data, PIR results view. Organized programmatically/geographically, no resolution linkage.

## Notes

- Portal tracks repeal/substitution lineage ("modification type") — a real active/superseded distinction. 1,287 resolutions since 1945, Conference only.
- Round 2 (2026-07-18) re-verified portal metadata: modification types Insertion/Substitution/Repeal present; no budget or implementation fields.

## Open questions
