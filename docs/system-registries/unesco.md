# UNESCO — United Nations Educational, Scientific and Cultural Organization

Dossier on registry-like systems for governing-body mandates. Part of the
survey behind the `/system` mandate-registry column; taxonomy and scoring
scheme in [`../un-system-registries.md`](../un-system-registries.md).

## Systems

- None scored. No centralized system. UNESCO has proposed establishing a decision-tracking system aligned with the UN Mandate Register (43 C/OEWG/2/INF.3.REV.2, 2026).

## Point assessment

| Point | Assessment |
| --- | --- |
| 1 documents | no evidence in round 1 |
| 2 mandates (active) | no — round 2 confirmed: no in-force/superseded tracking anywhere; only per-session decision listings |
| 3 budget-linked | no — Core Data Portal organizes budget/expenditure by projects, outputs, countries and IATI fields (Integrated Budget Framework tables by cost nature/output/funding source); no linkage to GC resolutions or EB decisions |
| 4 implementation-linked | no evidence in round 1 |
| 5 results-linked | no — C/5 implementation is reported at programme/output level (annual C/5 Implementation Report to the EB Spring session, e.g. 221 EX/5.II.A), not against specific decisions/resolutions |
| 6 interoperability | deferred (later round) |

## Related portals (not linked to mandates)

- **Core Data Portal** — <https://core.unesco.org/> — replaced the UNESCO Transparency Portal (opendata.unesco.org now 301-redirects there); quarterly-updated project, budget/expenditure and IATI data organized by sector/country/output. Site returns 403 to non-browser clients; verified via redirect target and search descriptions.

## Notes

- Acknowledged gap: 43 C/OEWG/2/INF.3.REV.2 (18 May 2026) recommends establishing "a centralized decision-tracking system … aligned with the United Nations Mandate Register".
- Per-session EB decisions finding aid exists via UNESDOC (unesco.org/en/legal-affairs/decisions-exb), so bare document access is arguably present despite the null score.
- A Budget and Finance Committee (est. Nov 2024) monitors financial risks of programme implementation — governance-side, no public decision-linked tooling.

## Open questions

- Whether the proposed decision-tracking system materializes in the 43 C/5 cycle; points 4 and 6 unassessed.
