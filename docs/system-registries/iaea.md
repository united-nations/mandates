# IAEA — International Atomic Energy Agency

Dossier on registry-like systems for governing-body mandates. Part of the
survey behind the `/system` mandate-registry column; taxonomy and scoring
scheme in [`../un-system-registries.md`](../un-system-registries.md).

## Systems

- **GC Resolutions Archive** (Resolutions Database) — <https://www.iaea.org/gc-archives/type/resolutions>

## Point assessment

| Point | Assessment |
| --- | --- |
| 1 documents | yes |
| 2 mandates (active) | no — confirmed round 2; GC archive is a plain document list with no status (active/superseded) metadata |
| 3 budget-linked | no — budget lives in the programme-level "Agency's Programme and Budget" document (e.g. GC(69)/6, <https://www.iaea.org/sites/default/files/gc/gc69-6_0.pdf>), adopted by a GC resolution but with no system linking resolutions to resourcing |
| 4 implementation-linked | no evidence in round 1 |
| 5 results-linked | no — DG issues individual reports pursuant to specific GC resolutions as GC documents, but there is no system connecting resolutions to outcome reporting |
| 6 interoperability | deferred (later round) |

## Related portals (not linked to mandates)

- Budget overview page at iaea.org/about/overview/budget (existence known; site returned HTTP 402 to non-browser fetch in round 2).
- Biennial "Agency's Programme and Budget" documents in the GC document series (GC(69)/6 for 2026–2027, verified).

## Notes

- General Conference only (4,087 resolutions, session/type filters); no Board of Governors documents public.
- Round 2: iaea.org blocked non-browser fetches (HTTP 402) for HTML pages; findings verified via search-indexed GC PDFs and round-1 archive observations.
