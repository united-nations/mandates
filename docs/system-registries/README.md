# System registry dossiers

One dossier per UN system organization, documenting its registry-like
systems for governing-body mandates: what exists, what it covers, and how
it scores on the point scheme defined in
[`../un-system-registries.md`](../un-system-registries.md)
(documents · mandates · budget-linked · implementation-linked ·
results-linked · interoperability).

Workflow: research rounds (usually parallel subagents, one owner per file)
update dossiers in place — verify every URL before recording it, keep the
point-assessment table and the last-verified line current, and put
anything nuanced or unresolved under Notes / Open questions. The data in
`website/src/data/un-system.json` is then updated from the dossiers,
never the other way around.
