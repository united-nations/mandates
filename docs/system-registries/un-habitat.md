# UN-Habitat — United Nations Human Settlements Programme

Dossier on registry-like systems for governing-body mandates. Part of the
survey behind the `/system` mandate-registry column; taxonomy and scoring
scheme in [`../un-system-registries.md`](../un-system-registries.md).

## Systems

- **Resolution Tracker** (Implementation Tracker) — <https://unhabitat.org/unhabitat-resolutions>

## Point assessment

| Point | Assessment |
| --- | --- |
| 1 documents | yes |
| 2 mandates (active) | partial — tracker status labels ("Implemented" / "Under implementation" / "Cost-neutral") distinguish completed from ongoing resolutions; no in-force/superseded registry |
| 3 budget-linked | yes — per-resolution resource requirements, resources mobilized and funding gap (e.g. res 2/1: $1,085K required, $384K mobilized, $701K gap) |
| 4 implementation-linked | yes |
| 5 results-linked | partial — implementation summaries report narrative outcomes per resolution (e.g. res 2/6: USD 24M channeled to local financing in 8 countries), not a structured results framework |
| 6 interoperability | deferred (later round) |

## Related portals (not linked to mandates)

None live. The historical Open UN-Habitat IATI portal (open.unhabitat.org, launched 2013) no longer resolves (DNS failure on 2026-07-18).

## Notes

- Web tracker mandated by Assembly res 2/10, updated semi-annually; shows per-resolution programmatic status, financial requirements and funding gaps — the only budget-linked mandate case in the survey. Round 2 re-verified all fields directly on the tracker.
- Covers Assembly sessions 1 (res 1/1–1/5) and 2 (res 2/1–2/10); references implementation reports (e.g. HSP/EB.2024/INF/16) without embedding them.

## Open questions
